# Cultivated Living

One page, mobile first preview site for Cultivated Living (Pty) Ltd, a plant nursery in Menlo Park, Pretoria.
Static HTML, CSS and a little JavaScript. No build step. Open `index.html` in a browser, or serve the folder with any static server.

Live site (GitHub Pages): https://darrenrosbon.github.io/cultivated-living-site/
